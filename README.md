# Katlego Queeneth Matlhoko | Personal Brand Website

A responsive personal brand and portfolio website showcasing **Katlego Queeneth Matlhoko** as a woman in tech, developer, entrepreneur and sales professional.

## ✨ Features

* Responsive design for desktop, tablet and mobile
* Personal story and motherhood sections
* Portfolio and business projects
* Skills and problem-solving approach
* Women in tech and career journey
* Email, Call and WhatsApp contact buttons
* Background videos with reduced-motion support
* Mobile navigation menu

* HTML5
* CSS3
* Vanilla JavaScript
* Google Fonts
